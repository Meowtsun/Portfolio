💬 Sceny - Reinventing Dialogues

Don't dialogues system contain more words that's not actually a dialogues?, What if there was.. none? 

--demo.lua
local system = character "System" {};
local you = character "You" {};

local counting = scene {

	scripts(function(content) 
		if content.get("count") >= 10 then
			return leave()
		end
	end);
    
	system "counting.. $[count]";
	state.increment "count";
    
	reread();
}


local sendevent = scene {

	system "I can also send values back";
	you "To where?";
    
	system "To parser that you're going to use!";
	you "so I can get values from these dialogues?";
	system "Yes!, like this";
    
	event(state.get("count"));

	you "That's useful, can I have tables?";
	system "Why not?, just maybe don't nest them";
	you "Why?";
	system "Predictability";
	you "I see";
    
	event({
		count = state.get("count")
	});
	
	system "There's also state.map and state.derived!";
    
	state.derived 'derived' (function(content)
		return content.get('count') * 2
	end);
	
	state.map 'map' (function(content)
		return content.get('count') + 2
	end);
	
	you "What's the difference?";
	system "derived changes as state changes, but map doesn't!";
	system "map has to be explicitly re-read again!";
	
	system "we can also attach metadata!";
    system "only to questions and answers though";
	you "metadata?";
    
	system "Yes!, let me build example question" {
		system "This is answer 1" {
			meta({
				isVisible = state.get('this_answer_id_visible')
			})
		}
	};
	
	system "It doesn't do anything by itself";
    your "but it give runtime information";
	system "Yes, right to your parser!";
	you "I see";
}

local morescene = scene {
	system "Exactly!";
	system "but I can also repeat things";
	you "Repeat things?";
    
	system "Yes, for example, Let me count from 1 to 10";
	system "I'm going to start from 1";
    
	state.set "count" (1);
	counting();
	sendevent();
}

local declined = scene {
	system "Too bad! I'm going to explain anyway";
	you "Alright..";
}

local introduction = scene {

	system "Hello this is Sceny demo";
	system "This look cool isn't it?";
	system "I'm taking right now!";
    
	system "I can also ask you questions";
	system "Is this cool?" {
		you "It is!";
		you "No" {
			declined();
		};
	};

	system "Nice! guess else I can do?" {
		you "Making more scenes?" {
			morescene();
		};
	};

	system "And I can come back to here too as scene is ended!";
	you "This look like programming language";
	system "It does!";
    
	you "What if I don't want to comeback?";
	system "Then you use goto!, It's just like require()!";
	system "Reminding that goto will reset all state";
	you "Why?";
    
	system "I treated as previous conversation is ended";
	you "I see, How do you use it though?";
	system "Like this!";

	goto './Other_Module';
}

return introduction

Sceny is a small language for building interactive scenes
Conversations, choices, events, and story flow
can all be written together in one place!

💰 LootSet - Reimagining LootTable

Why map your config so LootTable understands it?
What if your LootTable can just.. know how to read weight?
from you telling it how to do so, of course 

--demo.lua
local config = {
    item1 = {
        weight = 10;
        data = {...}
    },
    
    item2 = {
        weight = 10;
        data = {...}
    },
}

-- optional
local function filter(key, value)
    return true
end

local lootSet = LootSet.from(config, '@item/weight', filter)
local luck = 0 -- optional

local name, item = lootset:roll(luck)
lootset:sample(100, luck) -- prints to output

LootSet is used to roll random items from luck and weight
but instead of making new tables manually or writing
your item table in a very specific way every single time
What if you just.. tell your LootSet how to read your items?

📑 EmbedMaker - I can also just.. do it

Discordjs embedbuilder made in luau for developdment
Beautiful usages and features still feel familiar!
You can now easily build discord embeds for webhooks! 

--demo.lua
local FooterBuilder = EmbedMaker.FooterBuilder
local FieldBuilder = EmbedMaker.FieldBuilder

local embed = EmbedMaker.new()
    :SetTitle("Hello World")
    :SetDescription("This is a description")
    :SetColor(Color3.fromRGB(255, 0, 0))
    :AddFields(
        FieldBuilder.new()
            :SetName("Field1")
            :SetValue("Value1")
            :SetInline(true)
        ,
        FieldBuilder.new()
            :SetName("Field2")
            :SetValue("Value2")
        ,
        -- providing table also works ofc
        {name = "Field3", value = "Value3"}
    )
    :SetFooter(
       FooterBuilder.new()
        :SetText("This is a footer text")
    )

local json = embed:ToJSON()
print(json)
